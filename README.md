# 🌊 Wavelet Application

A Django web application that demonstrates **image encryption, compression, and denoising** using **Wavelet transforms**.  
This project combines **image processing** with a **web interface**, showing how wavelet-based methods can be applied in practice.

---

## 🔍 Overview
This project explores the use of wavelet transforms in image processing and wraps the functionality in a Django web app.  
Users can upload images and apply operations such as:  
- 🔐 **Encryption & Decryption**  
- 📦 **Compression**  
- 🎨 **Denoising**

---

## ✨ Features
- Upload and process images directly in the web interface.  
- Apply wavelet-based transformations for image compression.  
- Encrypt and decrypt images with a key-based mechanism.  
- Denoise images while preserving important details.  
- Store and manage images in an SQLite database.  

---

## 🛠 Tech Stack
- **Backend:** Python, Django  
- **Image Processing:** PyWavelets, NumPy
- **Frontend:** HTML, CSS, Django Templates  
- **Database:** SQLite
